# Convenciones de commits

El formato básico es:

```text
<tipo>: <descripción>
```

Opcionalmente, se puede incluir un ámbito:

```text
<tipo>(ámbito): <descripción>
```

## Tipos de commits

|Tipo|Propósito|
|-|-|
|feat|Añadir una nueva funcionalidad, operación o capacidad relacionada con la teoría de conjuntos.|
|fix|Corregir un comportamiento incorrecto o un error.|
|research|Investigación matemática, trabajo teórico o experimentos.|
|test|Añadir o modificar pruebas.|
|docs|Añadir o modificar documentación.|
|refactor|Reestructurar el código sin cambiar su comportamiento.|
|perf|Mejorar el rendimiento.|
|build|Modificar dependencias, empaquetado o configuración de construcción.|
|ci|Modificar la integración continua o la configuración de automatización.|
|chore|Tareas generales de mantenimiento que no corresponden a otra categoría.|
